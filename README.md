# מליגה ג׳ למקצוענות

משחק קריירה בעברית לשחקן ישראלי בכדורגל או בכדורסל: מתחילים בליגות הנמוכות עם עבודה אזרחית, ומטפסים עד ליגת העל.
מובייל קודם, RTL מלא, עיצוב כהה עם זהב, אייקונים של `lucide-react` בלבד (בלי אימוג׳י).

## מה יש במשחק

- **סמלי קבוצות** נוצרים אוטומטית לכל מועדון (צבעי המועדון, תבנית וראשי תיבות), כולל סמלי נבחרות.
- **מסך פתיחה** עם המשך קריירה שמורה או קריירה חדשה, ופתיח קצר עם כפתור "דלג".
- **תמונות AI** לכל סיטואציה: `npm run photos:ai` מוריד 57 תמונות חינמיות מ-Pollinations.ai (בלי מפתח ובלי תשלום) לפי ההנחיות ב-`scripts/ai-photo-prompts.json`, שומר אותן ב-`public/images/<שם>.jpg` (9:16 לפתיחה, 16:9 לשאר) ומחבר אותן למשחק. `npm run build:single` אורז את המשחק עם התמונות לקובץ HTML אחד (`dist/liga-gimel.html`). כל עוד לא הותקנו תמונות, המשחק טוען תמונות מ-Wikimedia Commons.
- **משחק חי**: שעון רץ, פרשנות דקה אחר דקה, שמות שחקנים לכל סגל, כרטיסים, חילופים, מחציות ורבעים, הארכה בכדורסל. הרגעים שלכם קופצים בדקה האמיתית שלהם ומשנים את התוצאה בזמן אמת.
- **תנאי משחק**: מגרש או אולם, קהל, מזג אוויר, שופט, יום ושעה, ודרבי. הם משפיעים על הסיטואציות שעולות ועל הקושי שלהן.
- **1,277 סיטואציות שונות**: אירועים כתובים ביד, ועוד תבניות (`src/data/events/templates`) שמשולבות עם הקשרים (דקה, תוצאה, מזג אוויר, דרבי, עייפות מהעבודה, מגרש גרוע, קהל גדול) ועם וריאציות.
- **קפטן**: שחקן הרכב עם אמון מאמן גבוה וציונים טובים מקבל הצעה מהמאמן לענוד את סרט הקפטן. לקפטן יש אירועים משלו, בונוס שכר ומורל, והמאמן יכול לקחת את הסרט בחזרה.
- **חולצה אישית** עם השם והמספר שבחרתם, בצבעי המועדון ועם ספונסר החולצה שלו.
- **בית ומועדון**: כותבים איפה גרים (או רוצים לגור), והמשחק מציע את המועדונים הקרובים לפי מרחק בק״מ (`src/data/places.ts`). מועדון רחוק אומר נסיעות שעולות אנרגיה וכסף, עד שחותמים על חוזה מקצועני עם דירה.
- **הכול לפי ביצועים**: המשחק עוקב אחרי הציונים ב-5 המשחקים האחרונים. ספונסרים וסוכנים פונים אליכם רק אחרי רצף טוב ומשחקים גדולים (ציון 8+), לא לפי מחזור או דירוג. רצף חלש, וספונסר יכול להקפיא את החסות.
- **תהילה**: מתחילים עם קומץ עוקבים. עוקבים ומוניטין מגיעים ממשחקים טובים, ופוסטים מתפשטים רחוק יותר אחרי הופעות חזקות. ככל שהליגה גבוהה יותר, יש יותר קהל.
- **התפתחות הדרגתית**: אימון ממלא חלק מנקודה (פס התקדמות לכל תכונה), ומשחקים טובים מוסיפים ניסיון. ההתקדמות מאטה ליד הפוטנציאל, עם הגיל ובעייפות. שחקן ממוצע עולה בערך 2 נקודות דירוג לעונה.
- **בחירת עמדה על המגרש**: העמדות מוצגות על מגרש כדורגל או על חצי מגרש כדורסל, עם הסבר על התפקיד והתכונות החשובות.
- **נבחרת ישראל**: בפגרות הנבחרות (אחרי מחזורים 4 ו-9) שחקן עם דירוג וציונים גבוהים מזומן לנבחרת הבוגרת או לנבחרת עד גיל 21, בכדורגל ובכדורסל.

## הרצה

```bash
npm install
npm run dev        # שרת פיתוח
npm test           # בדיקות: מנוע אירועים, חוק אפס אימוג׳י, ומשחק אוטומטי של 3 עונות לכל ענף
npm run build      # בדיקת טיפוסים ובנייה לפרודקשן
```

## הוספת אירועים

כל אירוע הוא אובייקט JSON עם 3 בחירות. בחירה עם `stat` ו-`difficulty` היא בדיקת מיומנות, ואז חייבת להיות לה תוצאת `fail`.

```json
{
  "id": "life_100",
  "type": "life",
  "sport": "both",
  "speaker": "המאמן",
  "title": "כותרת",
  "scene": "office",
  "text": "{שחקן} מ{קבוצה} פוגש את {יריבה} על {משטח}",
  "conditions": { "requiresJob": true, "maxDivision": 2 },
  "choices": [
    { "label": "...", "success": { "text": "...", "effects": { "fanRep": 3 } } },
    { "label": "...", "stat": "mental", "difficulty": 50,
      "success": { "text": "...", "effects": { "confidence": 4 } },
      "fail": { "text": "...", "effects": { "confidence": -3 } } },
    { "label": "...", "success": { "text": "...", "effects": {} } }
  ]
}
```

Placeholders: `{שחקן}` `{קבוצה}` `{יריבה}` `{עבודה}` `{סוכן}` `{משטח}` `{ספורט}`, ובמשחק גם `{תוצאה}` (התוצאה החיה), `{שופט}`, `{אצטדיון}`.
תנאים זמינים: `minDivision`, `maxDivision`, `requiresJob`, `requiresAgent`, `requiresCaptain`, `contract`, `minOvr`, `positions`, `matchResult`, `minMatchday`, `weather`, `derby`.

תבנית (template) היא סיטואציה בסיסית; המחולל (`src/services/eventGenerator.ts`) משלב אותה עם ההקשרים שב-`contexts.json`, שמשנים טקסט, שעון, קושי ותגמול. אירועי חיים משתמשים ב-`vars` לווריאציות (`{$name}`).
השדה `scene` בוחר איור (למשל `fb_penalty`, `bb_three`, `locker`, `press`, `phone`). אירועים עם `trigger` נבחרים רק בהקשר מיוחד (למשל `national_pre`).
אירועי בתוך משחק עם `"clutch": true` משאירים את המשחק צמוד כך שההחלטה מכריעה אותו.
המנוע מסנן ומגריל לפי משקל ומונע חזרה על אירועים שנראו לאחרונה, כך שאפשר להגדיל את המאגר לאלפי אירועים בלי לשנות קוד.

## תמונות

התמונות נשמרות ב-`public/photos` ונרשמות ב-`src/data/photoManifest.json` כולל קרדיט ורישיון (מוצגים במסך "קרדיטים לתמונות").

```bash
node scripts/photos.mjs search            # מוריד מועמדות מ-Openverse (CC0 / CC BY / CC BY-SA בלבד) לתיקייה photo-candidates
node scripts/photos.mjs pick fb_penalty=2 # מתקין את המועמדת שנבחרה, מוקטנת ודחוסה למובייל
node scripts/photos.mjs add title my.jpg "שם הצלם" "רישיון"   # תמונה משלכם
```

מפתחות: `title`, `intro_1..3`, כל ערכי `scene` של האירועים (למשל `fb_penalty`, `bb_three`, `locker`, `press`), ו-`stadium_football` / `stadium_basketball` / `field_football` / `field_basketball`.
